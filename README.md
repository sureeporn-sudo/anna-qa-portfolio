# Anna — Creative QA Portfolio

A creative, responsive portfolio for Sureeporn (Anna) Apaikawee, a junior QA engineer based in Vancouver.

## Highlights

- Editorial computer-workspace design
- Responsive layout for desktop and mobile
- QA toolkit presented as a terminal
- Selected automation, data-driven testing, and CI/CD projects
- Accessible navigation and reduced-motion support

## Tech stack

- React
- TypeScript
- Vinext / Vite
- Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in your terminal.
